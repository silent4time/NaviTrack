# NaviTrack (ناویار) | سامانه ردیابی آنلاین و مدیریت ناوگان

سامانه وب ردیابی زنده وسایل نقلیه به سبک **Protrack365** با پشتیبانی از سخت‌افزارهای GT06/Concox.

## ویژگی‌های فعلی

- **رابط کاربری نزدیک به پروتراک**: سایدبار فهرست دستگاه‌ها با وضعیت رنگی، باکس اطلاعات شناور، مارکرهای جهت‌دار روی نقشه.
- **ثبت و مدیریت دستگاه با IMEI**: اعتبارسنجی، تخصیص به مشتری، تمدید لایسنس با یک کلیک در پنل ادمین.
- **سیستم لایسنس مبتنی بر IMEI**: صدور، فعال‌سازی و تمدید اشتراک.
- **پنل توزیع‌کننده و پنل کاربر نهایی**.
- **دریافت داده سخت‌افزار**:
  - HTTP: `/api/gps/data`
  - **TCP Listener پروتکل GT06** روی پورت `5023`
  - موقعیت‌های دریافتی هر ۴ ثانیه روی نقشه زنده به‌روز می‌شوند.
- **گزارش‌های ناوگان**: خلاصه عملکرد و جدول دستگاه‌ها.
- **حصار جغرافیایی**: تعریف محدوده، تخصیص دستگاه و هشدار ورود/خروج.
- **قطع/وصل سوخت از راه دور** (شبیه‌سازی‌شده + صف فرمان).
- **شبیه‌ساز زنده** برای تست بدون سخت‌افزار.
- **نقشه سازگار با ایران**.

## راه‌اندازی

```bash
git clone https://github.com/silent4time/NaviTrack.git
cd NaviTrack
npm install
npm run dev
```

- وب: `http://localhost:3000`
- GT06 TCP: پورت `5023`

ورود پیش‌فرض توزیع‌کننده: `dealer` / `123456`

## اتصال سخت‌افزار GT06

```
APN,internet#
SERVER,1,YOUR_PUBLIC_IP,5023,0#
RESET#
```

پکت‌ها در کنسول و از طریق `/api/hardware/logs` قابل مشاهده‌اند و موقعیت‌ها روی نقشه ظاهر می‌شوند.

## ساختار

```
server.ts                  # Express + GT06 TCP + APIها
src/components/            # UI پروتراک‌مانند
src/services/storage.ts    # ذخیره‌سازی محلی + لایسنس + geofence
```

## وضعیت توسعه

- UI اصلی (سایدبار، اینفوباکس، مارکرها) بهبود یافته
- اتصال زنده GT06 به نقشه فعال
- پنل ادمین لایسنس (تمدید) فعال
- گزارش‌ها و geofence بهبود یافته

توسعه‌یافته به عنوان جایگزین/مکمل پروتراک برای محیط‌های داخلی.

## PWA (نصب روی موبایل)

سامانه به صورت Progressive Web App آماده است. در مرورگر موبایل (Chrome یا Safari):

1. سایت را باز کنید.
2. منوی مرورگر → «Add to Home Screen» یا «نصب اپ» را انتخاب کنید.
3. آیکون «ناویار» روی صفحه اصلی ظاهر می‌شود و مانند اپ مستقل باز می‌شود.
