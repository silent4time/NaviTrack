# NaviTrack (ناویار) | سامانه ردیابی آنلاین و مدیریت ناوگان

سامانه وب حرفه‌ای ردیابی زنده وسایل نقلیه و مدیریت ناوگان، طراحی‌شده به سبک **Protrack365** با پشتیبانی از سخت‌افزارهای رایج (پروتکل GT06 / Concox).

---

## ویژگی‌های کلیدی

- **رابط کاربری به سبک پروتراک**: سایدبار فهرست دستگاه‌ها با فیلتر متحرک/متوقف/آفلاین، باکس اطلاعات زنده، بازپخش مسیر، نقشه Leaflet.
- **ثبت دستگاه با IMEI**: اعتبارسنجی Luhn، اطلاعات خودرو و پلاک ایرانی.
- **سیستم لایسنس مبتنی بر IMEI**: صدور کد لایسنس (`NVTRK-XXXX-XXXX-XXXX`)، فعال‌سازی، تمدید و کنترل دسترسی.
- **پنل توزیع‌کننده / ادمین**: مدیریت مشتریان، صدور لایسنس دسته‌ای، مشاهده دستگاه‌ها.
- **پنل کاربر نهایی**: فقط دستگاه‌های خودش را می‌بیند.
- **دریافت داده سخت‌افزار**:
  - Endpoint HTTP: `POST/GET /api/gps/data?imei=...&lat=...&lon=...`
  - **TCP Listener پروتکل GT06** روی پورت `5023` (قابل تغییر با متغیر `GT06_PORT`).
- **صف فرمان از راه دور**: قطع سوخت (`RELAY,1#`)، وصل مجدد و غیره.
- **شبیه‌ساز زنده**: برای تست بدون سخت‌افزار واقعی.
- **نقشه سازگار با ایران**: لایه‌های OSM / Carto / Esri بدون نیاز به VPN.

## راه‌اندازی سریع

```bash
git clone https://github.com/silent4time/NaviTrack.git
cd NaviTrack
npm install
npm run dev
```

سرور روی `http://localhost:3000` بالا می‌آید و همزمان **GT06 TCP** روی پورت `5023` گوش می‌دهد.

### ورود پیش‌فرض
- نقش توزیع‌کننده: حساب `dealer` / رمز `123456`
- (در کد قابل تغییر است)

## اتصال سخت‌افزار واقعی (GT06 / Concox و مشابه)

بیشتر ردیاب‌های ارزان‌قیمت سازگار با پروتراک از پروتکل **GT06** استفاده می‌کنند.

1. یک SIM با اینترنت فعال در دستگاه قرار دهید.
2. با SMS دستورات زیر را بفرستید (دستور دقیق بسته به مدل ممکن است کمی فرق کند):

```
APN,internet#
SERVER,1,YOUR_PUBLIC_IP_OR_DOMAIN,5023,0#
RESET#
```

3. دستگاه به سرور شما متصل می‌شود و پکت‌های Login + Location را می‌فرستد.
4. لاگ‌ها در کنسول سرور و از طریق `/api/hardware/logs` قابل مشاهده است.

> برای محیط توسعه، از ابزارهایی مثل `nc` یا اسکریپت تست می‌توانید پکت باینری بفرستید.
