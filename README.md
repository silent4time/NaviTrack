# NaviTrack (ناویار) | سامانه ردیابی آنلاین و مدیریت ناوگان

یک نرم‌افزار حرفه‌ای، سریع و تحت وب برای ردیابی زنده وسایل نقلیه و مدیریت دارایی‌ها بر پایه نقشه‌های **OpenStreetMap** و کتابخانه سبک **Leaflet**، همراه با سیستم ثبت سخت‌افزار از طریق **کد IMEI** و فروشگاه/مدیریت **کدهای لایسنس**.

---

## 🚀 ویژگی‌های کلیدی

- **ثبت دستگاه با شناسه سخت‌افزاری (IMEI Registration)**:
  - دریافت کد ۱۵ رقمی با اعتبارسنجی الگوریتم لوهن (Luhn Algorithm)
  - پشتیبانی از پروتکل‌ها و مدل‌های محبوب: Teltonika، Concox، SinoTrack، Coban و...
  - ثبت اطلاعات کامل خودرو، پلاک استاندارد ایران، نوع دارایی و راننده مسئول
  - ۱ ماه اشتراک هدیه تست خودکار پس از ثبت نام

- **سیستم فروش و فعال‌سازی لایسنس (License Store & Activation)**:
  - پلن‌های متنوع اشتراک (۱ ماهه پایه، ۳ ماهه اقتصادی، ۶ ماهه پیشرفته، ۱۲ ماهه طلایی ناوگان)
  - درگاه پرداخت آنلاین شبیه‌سازی شده و صدور آنی کد فعال‌سازی `NVTRK-XXXX-XXXX-XXXX`
  - بخش اختصاصی فعال‌سازی و تمدید لایسنس روی شناسه IMEI
  - پنل ادمین جهت صدور تکی و دسته‌ای لایسنس برای نمایندگان فروش

- **نقشه سبک و روان بر پایه Leaflet & OpenStreetMap**:
  - بارگذاری بسیار سریع و بدون نیاز به کلیدهای تحریمی
  - سوئیچ بین حالت‌های:
    - خیابانی استاندارد (OpenStreetMap)
    - نمای شب و تاریک اتاق مانیتورینگ (CartoDB Dark Matter)
    - نمای هوایی ماهواره‌ای (Satellite)
    - ناوبری شهری روشن (CartoDB Positron)
  - چرخش و زاویه برداری متحرک خودروها (Heading/Bearing 0-360°)
  - نمایش ردپای مسیر (Polyline Trail) و حصارهای جغرافیایی (Geofence)

- **تله‌متری زنده و دستورات کنترلی**:
  - سرعت لحظه‌ای (km/h) با وضعیت سوئیچ احتراق (ACC On/Off)
  - ولتاژ باتری، باتری پشتیبان و قدرت سیگنال آنتن
  - **فرمان قطع کن موتور (Engine Immobilizer)**: ارسال دستور رله قطع سوخت از راه دور
  - **بازپخش تاریخچه تردد (History Playback)** با کنترل سرعت و اسلایدر زمانی
  - مرکز هشدارهای امنیتی (سرعت غیرمجاز، لرزش، تصادف، قطع برق)

## 🛠️ پیش‌نیازها و راه‌اندازی سریع

برای اجرای پروژه روی سیستم شخصی یا سرور:

```bash
# ۱. کلون کردن مخزن
git clone https://github.com/silent4time/NaviTrack.git
cd NaviTrack

# ۲. نصب وابستگی‌ها
npm install

# ۳. اجرای محیط توسعه
npm run dev
```

پروژه به صورت پیش‌فرض روی آدرس `http://localhost:3000` یا پورت تعیین‌شده اجرا می‌شود.

برای ساخت بیلد نهایی عملیاتی (Production Build):
```bash
npm run build
npm run preview
```
